# Mehoy Malloy AI Runtime

A local-first, backend-agnostic AI model runtime.

## Status

Early. No runtime is implemented yet. The repository currently contains project rules,
license terms, and research findings.

Architecture decisions are open. See
[docs/research/runtime-landscape-distillation.md](docs/research/runtime-landscape-distillation.md)
for the evidence gathered so far, the alternatives under consideration, and the decisions
that block implementation.
